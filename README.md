## Опис файлів

1.  **Обчислення функції:**

    - Реалізовано програму для обчислення значення функції f(x) відповідно до заданих умов (див. звіт).
    - Виконано двома способами:
      - З використанням скороченої форми оператора `if`.
      - З використанням повної форми оператора `if...else if...else`.

2.  **Визначення типу трикутника:**

    - Розроблено програму, яка визначає тип трикутника (рівносторонній, рівнобедрений, різносторонній) на основі довжин його сторін.
    - Програма також перевіряє можливість існування трикутника з заданими сторонами.

3.  **Вивід назви дня тижня:**
    - Створено програму, яка виводить назву дня тижня (понеділок, вівторок, ...) за його порядковим номером (1-7).
    - Реалізовано з використанням конструкції `switch...case`.
